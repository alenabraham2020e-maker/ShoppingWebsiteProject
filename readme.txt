Shopping Website — E-Commerce Web Application

A dummy e-commerce web application built using ASP.NET Web Forms, C#, and SQL Server, featuring product browsing, cart management, and stock validation.

Features:
- Product listing by category with detailed product pages
- Stock validation before adding items to cart
- Fully functional cart page with edit, update, delete, and automatic subtotal recalculation
- User login and account management
- SQL Server database schema across 10 tables covering products, categories, cart, orders, payments, and accounts

Tech Stack:
- Frontend: ASP.NET Web Forms, HTML, CSS, Bootstrap
- Backend: C#
- Database: Microsoft SQL Server

Status: This project is a work in progress, with core features (product browsing, cart, stock validation) implemented and further enhancements ongoing.
